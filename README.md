## 🎮 How to Use

### Basic Operation

1. **Set Click Interval** - Use the slider or number input to set milliseconds between clicks (e.g., 100ms = 10 clicks per second)
2. **Choose Click Type** - Select left, right, middle, or double-click from the dropdown
3. **Set Hotkey** - Press the hotkey field and type your preferred keyboard shortcut (default is F6)
4. **Start Clicking** - Press your hotkey or click the Start button
5. **Stop Clicking** - Press the same hotkey again or click Stop

### Advanced Settings

- **Repeat Count** - Set a specific number of clicks before stopping automatically
- **Random Delay** - Add randomness to click intervals for more natural behavior
- **Click Position** - Choose to click at current mouse position or a fixed location
- **Sound Effects** - Enable or disable click sounds

## 🔧 Troubleshooting

### Common Issues

**Application won't start**
- Ensure you have Windows 10 version 1809 or later
- Try running as administrator (right-click > Run as administrator)
- Update Windows via Settings > Windows Update

**Antivirus warning**
- WinClicker is completely safe. Some antivirus software may flag autoclickers as potentially unwanted programs. Add WinClicker to your antivirus exclusions list.

**Hotkey not working**
- Make sure no other application is using the same hotkey
- Try a different key combination (e.g., F7, Ctrl+Shift+F1)
- Close other applications that might interfere

**Clicks not registering**
- Ensure WinClicker has focus when starting
- Check if you're clicking in a window that requires administrator privileges
- Try running WinClicker as administrator
